# Ownward Labs

Ownward Labs is a customizable customer relationship management workspace for managing contacts, companies, opportunities, activities, and workflows. The platform includes a flexible data model, APIs, integrations, and self-hosting options.

Learn more at [ownward.agency](https://www.ownward.agency/).

## Development

This repository is an Nx monorepo managed with Yarn 4. The main packages are:

- `packages/twenty-front` — web application
- `packages/twenty-server` — API and application services
- `packages/twenty-docs` — product and developer documentation
- `packages/twenty-website` — public website

Use Node.js 22 and run `yarn install` before using the Nx targets. For local development, see the package-specific instructions and `CLAUDE.md`.
