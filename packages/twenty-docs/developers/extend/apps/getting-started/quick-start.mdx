## Before you start

Use Node.js 24.5+ or 26.5+ and Yarn 4 (via Corepack: `corepack enable`; on Node 26, install it first with `npm install -g corepack`). Install the CLI globally; your app keeps its own SDK dependencies.

<Note>
Building Ownward Labs apps is officially supported on Unix systems (macOS and Linux) only. On Windows, work inside WSL 2.
</Note>

## Create the project

```bash
npm install -g ownward-cli
ownward app init my-twenty-app
cd my-twenty-app
yarn install
```

`app init` writes the template only. It does not install dependencies, initialize Git, start Docker, authenticate, or sync. Customize the display name and description with `--display-name` and `--description`; use `--path` for a different destination.

## Connect to Ownward Labs

Use an existing workspace, or start a [local server](/developers/extend/apps/getting-started/local-server), then sign in:

```bash
ownward auth login --url https://your-workspace.ownward.agency --name dev
```

## Sync your changes

For the first sync, explicitly allow registration and installation:

```bash
ownward app apply --create
```

Then start the development watcher:

```bash
ownward app dev
```

Use bounded commands for scripts and agents:

```bash
ownward app plan
ownward app apply
```

`plan` previews changes. `apply` uploads and synchronizes once. Use `--no-prune` to keep remote entities missing from source, or `--yes` to permit object and field deletions without a prompt. All three commands require an authenticated remote and registration ownership.

## What you can build

Apps are composed of **entities** — each defined as a TypeScript file with a single `export default`:

| Entity                 | What it does                                                                        |
| ---------------------- | ----------------------------------------------------------------------------------- |
| **Objects & Fields**   | Custom data models (Post Card, Invoice, etc.) with typed fields                     |
| **Logic functions**    | Server-side TypeScript triggered by HTTP routes, cron schedules, or database events |
| **Front components**   | React components that render inside Ownward Labs UI (side panel, widgets, command menu) |
| **Skills & Agents**    | AI capabilities — reusable instructions and autonomous assistants                   |
| **Views & Navigation** | Pre-configured list views and sidebar menu items                                    |
| **Page layouts**       | Custom record detail pages with tabs and widgets                                    |

Full reference: [Concepts](/developers/extend/apps/getting-started/concepts).

## Build with AI agent skills

Official Ownward Labs [Agent Skills](https://skills.sh/) teach coding agents the full app workflow: scaffolding, entity development, sync and deploy operations, and marketplace publishing. They install into Claude Code, Codex, Cursor, Pi, and any other harness supported by the `skills` CLI, and work against any Ownward Labs instance, including self-hosted custom domains and localhost.

```bash filename="Terminal"
# List the available skills
npx skills add https://github.com/Krishna-Sai3112/Ownward_CRM/tree/agent-skills --list

# Install the scaffolding and development skills
npx skills add https://github.com/Krishna-Sai3112/Ownward_CRM/tree/agent-skills --skill create-app
npx skills add https://github.com/Krishna-Sai3112/Ownward_CRM/tree/agent-skills --skill develop-app
```

Each skill installs with its own reference docs. The `agent-skills` branch becomes available after the first successful publish from `main`; before that, follow the [local build instructions](https://github.com/Krishna-Sai3112/Ownward_CRM/tree/main/packages/twenty-agent-skills#local-development).
