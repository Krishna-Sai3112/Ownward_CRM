## 概要

Ownward Labs は拡張性を念頭に設計されています。 当社の API、Webhook、アプリフレームワークを使用して既存のツールと統合し、カスタム機能を構築できます。

## 現在できること

* **API**: REST または GraphQL を使用して、プログラムから CRM データをクエリおよび変更します。
* **ウェブフック**: Ownward Labs でイベントが発生したときにリアルタイム通知を受信します。
* **アプリ**: Ownward Labs の機能を拡張するカスタムアプリケーションを構築する
