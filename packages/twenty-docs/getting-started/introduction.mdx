Ownward Labs is a CRM workspace for organizing customer records and the work connected to them. Teams can configure the data they track, arrange records in views, and use workflows and integrations to connect their existing processes.

## Choose how to run it

Use the Ownward Labs instance provided for your organization, or follow the self-hosting guide to run the application on infrastructure you manage. Availability and sign-in options depend on how that instance is configured.
