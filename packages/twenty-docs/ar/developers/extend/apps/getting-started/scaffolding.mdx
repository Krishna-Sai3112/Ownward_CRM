## نظرة عامة

استخدم واجهة CLI المستقلة لإنشاء كائن أو حقل أو دالة منطقية أو مكوّن أمامي:

```bash
ownward app add
ownward app add object --name invoice --name-plural invoices --no-input
ownward app add field --name amount --type NUMBER --object <object-uuid> --no-input
ownward app add logic-function --name send-invoice --no-input
ownward app add front-component --name invoice-panel --no-input
```

بدون خيارات، تطلب الطرفيات التفاعلية القيم المفقودة. بالنسبة إلى البرامج النصية والوكلاء، وفّر الحقول المطلوبة واستخدم `--no-input` أو `--json`.

يمكن أن يؤدي إنشاء الكائنات أيضًا إلى إنشاء عرض وعنصر تنقل وتخطيط صفحة سجل:

```bash
ownward app add object --name invoice --name-plural invoices \
  --create-view --create-navigation-menu-item --create-page-layout --no-input
```

بالنسبة إلى أنواع الكيانات الأخرى، اكتب ملف `define*` المقابل باستخدام `twenty-sdk/define` ومعرّف UUID v4 صالح. شغّل `ownward app typecheck` و`ownward app plan` قبل المزامنة.

يحدد `--path` دليل التطبيق، وليس مجلد إخراج مخصصًا. شغّل `ownward app add --help` للاطلاع على الخيارات المدعومة.
